## Takeaways for TFG-inspired work

- **No TFC / GregTech / TFG** entries in the Horizon registry yet.
- Community is mostly **QoL / HUD / client** native mods + shaders, not survival-tech packs.
- Notable **ports / inspired-by** already exist (native unless noted):
  - **Create for Horizon** (alpha) — rotating machines
  - **JEI** / JustEnoughItems, **Jade**, AppleSkin, Mod Menu
  - Distant Horizons, Continuity, Litematica (Horizonmatica), WorldEdit
  - Tectonic-Horizon, ProjectE (+ assets `.hmod`), Voice Chat
  - TreeFall / Veinminer / RightClickHarvest (some overlap with pack QoL)
- Content `.hmod` examples close to our earlier “start small” idea:
  - **Additional Lights** — decorative lamps (same niche as Simply Light)
  - **Factory Blocks** — industrial decor
  - **Macaw's Trapdoors** — large trapdoor set
  - asset packs paired with native mods (Wayfarer Stones, Voltz, Deepbore, ProjectE)
