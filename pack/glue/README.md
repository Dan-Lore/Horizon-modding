# Pack glue

Datapack-style glue for the TFG Horizon draft. Not a native mod.

## Contents

- `c:` item tags bridging GregTech / TFC / Ad Astra / Firmalife / vanilla
- Balance recipes (stick bundle, oil-from-lava, honey jar from raw honey)

## Install (manual, when smoking)

Copy or symlink this folder into an instance `datapacks/` (world) or merge tags into a content mod.
Do not native-build for glue-only changes.

Tracked as `pg_ore_dict_replacement` + `pg_balance_tweaks` in `docs/tfg-feature-catalog.json`.
